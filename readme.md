# ⚡ ANGOVO - 

## 📝 Introduction
**Angovo** est une application web intelligente dédiée au suivi et à la gestion de la consommation d'énergie (JIRAMA) à Madagascar. Elle permet aux utilisateurs de suivre leurs index, de consulter leurs factures et de maîtriser leur budget énergétique en toute simplicité.
